# Shoondili Auto CC Starter Pack

This is the visual starter pack for a dark-themed Shoondili Auto CC website.

## Included

- Dark-theme and light-theme SVG logo variants contour-traced from the supplied artwork
- SVG favicon
- Original supplied logo reference
- Five hyper-realistic non-vehicle background/process images
- One cinematic black Audi RS7 motion hero, clearly labelled as atmospheric artwork rather than inventory
- Responsive WebP variants at full, 1280px, and 768px
- Twelve custom service icons and three restrained SVG interface accents
- Asset manifest with exact intended usage
- Tivaly search and real-vehicle image rules

## Core rule

The files in this pack provide atmosphere around the vehicle catalogue. The Audi RS7 motion image is an approved hero exception and must never be presented as an available unit. All inventory and model-reference imagery must be scraped or retrieved from approved real manufacturer/dealer sources through Tivaly.

The business is a lean startup. Do not fabricate a dealership building, large office, fleet, branch network, staff team, or showroom.
