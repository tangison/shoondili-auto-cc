# Brand Tokens

```css
:root {
  --shoondili-ink: #090909;
  --shoondili-surface: #111111;
  --shoondili-raised: #181818;
  --shoondili-text: #f7f7f4;
  --shoondili-muted: #9b9b96;
  --shoondili-gold: #f5b400;
  --shoondili-gold-deep: #c98900;
  --shoondili-rule: rgba(255, 255, 255, 0.12);
}
```

Gold is a scarce accent. Do not use gold as a full-page background, large gradient, or decorative glow.

The website is dark-themed. Apply a restrained dark overlay when white copy sits over photography. Do not flatten every image into near-invisibility.
